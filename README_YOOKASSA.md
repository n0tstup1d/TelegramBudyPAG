# VEGA: интеграция ЮKassa

## Что реализовано

- создание платежа на 390 RUB через API ЮKassa;
- безопасная серверная аутентификация по shopId и секретному ключу;
- ключ идемпотентности для каждого запроса создания платежа;
- редирект пользователя на защищенную платежную страницу ЮKassa;
- ручная кнопка проверки оплаты;
- фоновая сверка ожидающих платежей без обязательного публичного webhook;
- проверка статуса, суммы, валюты и Telegram ID перед выдачей доступа;
- идемпотентная выдача бессрочного доступа;
- уведомление покупателя и команды об успешной оплате.

## Настройка

1. Получите `shopId` и секретный ключ в личном кабинете ЮKassa.
2. Добавьте в серверный `.env`:

```env
PAYMENT_PROVIDER_NAME=ЮKassa
YOOKASSA_SHOP_ID=ваш_shop_id
YOOKASSA_SECRET_KEY=ваш_секретный_ключ
YOOKASSA_RETURN_URL=https://t.me/USERNAME_БОТА
PAYMENTS_ENABLED=false
```

3. Установите обновление и выполните миграции:

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/alembic upgrade head
.venv/bin/python scripts/project_check.py
```

4. Сначала используйте ключи тестового магазина и оставьте `PAYMENTS_ENABLED=false` до проверки.
5. После теста измените `PAYMENTS_ENABLED=true` и перезапустите сервис.

## Важно

- Секретный ключ хранится только в `.env` на сервере.
- Бот считает платеж успешным только при статусе `succeeded` и дополнительно сверяет данные через API ЮKassa.
- Автоматические чеки НПД в этой интеграции не реализованы. Вопрос формирования чеков необходимо решать согласно настройкам вашего договора и налогового режима.
- Чтобы временно скрыть оплату от пользователей, оставьте `PAYMENTS_ENABLED=false`.
