# Защита платного контента VEGA

В проекте включены несколько независимых слоёв защиты:

1. Платные сообщения отправляются с `protect_content=True`, поэтому Telegram запрещает штатную пересылку и сохранение.
2. Каждый пользователь получает стабильный персональный код лицензии, рассчитанный через HMAC. Telegram ID в коде не публикуется.
3. В текст добавляется дополнительная невидимая zero-width метка. Она помогает сопоставлять скопированный текст, если редактор её не удалил.
4. Открытия разделов и материалов записываются в `content_stats`.
5. Слишком быстрое или массовое открытие вызывает временную защитную паузу и уведомление команды.
6. Постоянный бан автоматически не применяется. Администратор принимает решение вручную.
7. В карточке пользователя администратор видит код лицензии, количество открытий за час и состояние защиты.

## Переменные окружения

```env
CONTENT_PROTECTION_ENABLED=true
CONTENT_VISIBLE_WATERMARK=true
CONTENT_HIDDEN_FINGERPRINT=true
CONTENT_MARK_SECRET=длинный_случайный_секрет
CONTENT_SHORT_WINDOW_SECONDS=60
CONTENT_SHORT_MAX_VIEWS=30
CONTENT_LONG_WINDOW_SECONDS=3600
CONTENT_LONG_MAX_VIEWS=180
CONTENT_SHORT_BLOCK_SECONDS=600
CONTENT_LONG_BLOCK_SECONDS=3600
CONTENT_ALERT_COOLDOWN_SECONDS=1800
```

Секрет можно создать командой:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

После обновления кода необходимо применить миграцию:

```bash
.venv/bin/python -m alembic upgrade head
```

Ожидаемая версия Alembic:

```text
d5e6f7a8b9c0 (head)
```

## Важное ограничение

Защита Telegram затрудняет обычную пересылку и массовую выгрузку, но не может физически запретить фотографирование экрана или ручную перепечатку. Поэтому VEGA также использует персональные метки, журналирование и обновляемый сервис вместо единого скачиваемого архива.
