# Чеки самозанятого в VEGA

Бот не регистрирует доход в ФНС автоматически. После успешной оплаты он:

1. открывает покупателю доступ;
2. создаёт для платежа запись «чек ожидает оформления»;
3. уведомляет команду;
4. показывает платёж в `/admin` → `🧾 Чеки`;
5. после добавления ссылки, изображения или PDF отправляет чек покупателю и фиксирует историю.

## Рабочий сценарий

1. Откройте приложение «Мой налог» и сформируйте чек на полную сумму платежа.
2. В боте откройте `/admin` → `🧾 Чеки` → `⏳ Ожидают чека`.
3. Выберите нужный платёж.
4. Добавьте ссылку либо отправьте фото/PDF чека.
5. Проверьте покупателя и сумму на экране подтверждения.
6. Нажмите `📨 Отправить покупателю`.

Покупатель получит отдельное сообщение с чеком. Повторная отправка доступна из карточки уже отправленного чека.

## Напоминания

По умолчанию бот уведомляет командный чат через 2, 12 и 24 часа. Значения настраиваются в `.env`:

```env
RECEIPT_REMINDERS_ENABLED=true
RECEIPT_REMINDER_INTERVAL_SECONDS=900
RECEIPT_FIRST_REMINDER_HOURS=2
RECEIPT_URGENT_REMINDER_HOURS=12
RECEIPT_OVERDUE_HOURS=24
RECEIPT_ITEM_NAME=Предоставление бессрочного доступа к информационно-образовательной базе VEGA
```

## Важно

Кнопка `✅ Отметить отправленным вручную` используется только когда чек уже передан покупателю вне бота. Она не создаёт чек и ничего не отправляет в ФНС.
